# media-sdk monorepo

This monorepo scaffolds the media SDK ecosystem:

- packages/media-core (pure TypeScript core wrapping Pexels API)
- packages/media-react (React wrappers: Provider + hooks)
- packages/media-native (React Native wrappers)
- packages/media-ui-react (headless UI hooks/components)
- packages/media-ui-native (headless RN components)
- apps/web (example web app wiring media-react + media-ui-react)

See /skills/ for SKILL.md files used to guide AI coding agents.
